# Prompt release status

The frozen generation, preference-judge, and task-gate prompts are being reviewed for public release.

The release will include:

- the shared generation instruction;
- condition-specific memory wrappers;
- the preference-judge prompt and structured output contract;
- the task-gate prompt and structured output contract; and
- model and decoding configuration used for the paper snapshot.

No prompt will be published until embedded paths, examples, identifiers, and provider-specific credentials have been removed.

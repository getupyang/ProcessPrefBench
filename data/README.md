# Data release status

No naturalistic interaction data are included in the camera-ready pre-release.

The paper benchmark contains 66 source--target cases. A dedicated export pipeline will produce a minimized, de-identified representation conforming to `schemas/public-case.schema.json`. Internal research JSON files will not be copied into this directory.

Until the release gates in `RELEASE_STATUS.md` are satisfied, use the fully synthetic example in `examples/synthetic-demo-case.json` to inspect the public interface.
